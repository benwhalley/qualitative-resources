# Qualitative resources

Interactive teaching activities for PSYC611 (qualitative strand), served with GitHub Pages from
`main`.

- `build-an-argument/`: card-sort activity for Introductions and Results themes (week 6).

Each activity is a single self-contained `index.html` with no build step.

The source files live in the teaching folder, next to their printable versions. Don't edit the
copies here: change the source, then run `make publish` from that activity's folder (for
example `w6-resources/`), which copies the page here, commits and pushes.
